USER MANUAL / 0.4 PREVIEW

Start local.
Stay responsible.

Hunt Sift converts stored exports and source files into cautious review leads. It does not scan, replay, execute, enumerate, or submit anything.

Install locally.

PlatformCommand
Linux / macOS./scripts/install.sh
Windows PowerShell.\scripts\install.ps1
Any platformpython3 -m pip install --no-build-isolation -e .

Command surface.

NMAP / BURP / HAR

Review a saved export. The CLI never launches the originating tool or sends a request.

HTTP / STATIC

Review a raw response or selected source path for local-only context cues.

S3 POLICY

Parse a saved JSON policy. It never lists a bucket or accesses cloud data.

BOUNDARIES

Print the non-negotiable no-network, no-execution operating limits.

Workflow before output.

  1. Confirm written authorization and artifact handling permission.
  2. Run one local command against one explicit artifact.
  3. Read the evidence and next-step note; treat it as a review lead.
  4. Validate scope, actual data flow, and real impact before any disclosure.
Potential credential matches are redacted. Do not publish, validate, or reuse a suspected value. Use the owner’s private revocation and reporting route.

Quick commands.

hunt-sift burp --input ./exports/items.xml
hunt-sift har --input ./exports/session.har
hunt-sift s3 --input ./exports/policy.json
hunt-sift static --input ./source-export
hunt-sift boundaries
