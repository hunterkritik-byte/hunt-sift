# Security Policy

Please report suspected security issues in Hunt Sift privately to [projectvuln@gmail.com](mailto:projectvuln@gmail.com). Include the installed version, a concise description, the affected local input type, and sanitized reproduction steps.

Do not open public issues containing credentials, private data, exploit payloads, or artifacts that you are not authorized to share. Hunt Sift should remain an offline-only parser; reports that suggest live scanning, request replay, target discovery, payload generation, or code execution are outside the project's intended scope.
